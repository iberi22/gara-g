# Security Policy

## Reporting a Vulnerability

We take the security of GARA-G seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please send an email to **security@swal.ai**.

Include as much information as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

## Disclosure Policy

We follow a coordinated disclosure policy:
- We ask you to give us **90 days** to investigate and fix the issue before you make any information public.
- We will acknowledge receipt of your report within 48 hours.
- We will keep you informed of our progress.

## Bug Bounty

Southwest AI Labs (SWAL) operates a bug bounty program for qualified security reports. Rewards are determined based on the severity and impact of the vulnerability. Details on reward tiers and eligibility can be found on our [official website](https://swal.ai/bug-bounty).

## Supported Versions

Currently, only the latest version of the `main` branch is supported for security updates.

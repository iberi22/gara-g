# Architecture Decision Records (ADRs)

Este directorio contiene los Architecture Decision Records (ADRs) para el proyecto Garanet. Los ADRs documentan las decisiones arquitectónicas importantes, su contexto y sus consecuencias.

## Índice de ADRs

- [ADR-001: Visión General del Sistema](ADR-001-system-overview.md) - Describe la visión general y la arquitectura híbrida del sistema.
- [ADR-003: Integración DePIN](ADR-003-depin-integration.md) - Explica la arquitectura de la red DePIN, nodos y protocolos de malla.
- [ADR-004: Persistencia de Datos](ADR-004-data-persistence.md) - Documenta el uso de Drizzle ORM y la estrategia de esquemas y migraciones.
